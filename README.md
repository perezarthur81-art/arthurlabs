# Arthur Labs

Sitio de la compañía: https://arthurlabs.app

Página estática (HTML + CSS + JS, sin dependencias) en español, inglés y francés. Se publica con GitHub Pages.

## Páginas legales y de soporte

Privacidad, términos, reembolsos y soporte en español, inglés, francés y portugués.
El texto está en `_legal/<idioma>.json`; las páginas se generan con:

    python3 _legal/build.py

Rutas: `/privacidad/`, `/terminos/`, `/reembolsos/`, `/soporte/` (es) · `/en/…` · `/fr/…` · `/pt/…`.

## Enlaces cortos

- `/norte` → página de Norte (probar gratis y comprar)
- `/pro/norte`, `/pro/cuadre`, `/pro/clavuno` → pago de Pro en Hotmart
